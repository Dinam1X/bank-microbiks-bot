# Банк микробиксов хехе (@BankMicrobiksBot)

Telegram-бот на `python-telegram-bot` (async, v20+): счета, вклады под 10%
годовых (ежедневная капитализация), переводы, история операций.

Регистрация доступна только через бота компании — **@MicrobRobBot**, отдельный
репозиторий [pao-microb-bot](https://github.com/) (развёртывается отдельно).
Оба бота должны читать и писать **один и тот же** файл `db.json`, иначе баланс
и акции разъедутся — см. «Общая база» ниже.

## Установка

Требуется Python 3.10–3.12 (на 3.13+ не для всех пакетов есть готовые wheel).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и впишите токен бота (получить у
[@BotFather](https://t.me/BotFather)):

```
BOT_TOKEN_BANK=...
COMPANY_BOT_USERNAME=MicrobRobBot
```

## Запуск

```bash
python -m bot.main
```

## Общая база (важно при раздельных репозиториях)

Этот бот и `@MicrobRobBot` — два независимых процесса/деплоя, но работают с
одной и той же базой `db.json` (баланс, акции, транзакции общие). Если оба
бота крутятся на одном сервере/аккаунте bothost.ru с общей файловой системой —
задайте переменную окружения `MICROB_DB_PATH` **одинаково** в обоих
деплоях, например:

```
MICROB_DB_PATH=/home/user/microb-shared/db.json
```

Если хостинг изолирует каждый деплой в своём контейнере без общего тома —
общая база работать не будет, и это нужно решать на уровне хостинга
(например, общий persistent volume/диск, примонтированный в оба деплоя).

## Структура

```
bot/        main.py, handlers.py, keyboards.py, scheduler.py
common/     db.py (атомарная JSON-база с file lock), models.py (формулы),
            money.py (форматирование сумм), notify.py (уведомления)
data/       db.json создаётся автоматически при первом запуске
```
